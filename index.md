# Bienvenue cher héros!

Le royaume d’Alentina est tout aussi vaste que dangereux depuis que le roi Alphonse V a été annoncé gravement malade et cloîtré dans son lit. Un démon roderait apparemment quelque part dans ces coins, et aurait jeté un sort sur le royaume entier, le plongeant dans les ténèbres et la tourmente. 

Vous avez été repéré pour votre force, votre dextérité et votre foi pour protéger les plus faibles (et certainement pas car votre père est ministre du roi, non aucun rapport…) Le roi vous a donc choisi pour remettre de l'ordre dans le royaume avec pour récompense à la clé une montagne d’écus d’or !

Ainsi, vous êtes le dernier espoir d’Alentina, le futur du royaume dépend de vous… Ah oui, et si vous vous demandiez qui vous raconte tout cela, c'est moi, le narrateur. Cependant, je vous rassure, je n’interviendrais pas dans l’histoire… Normalement…

Choix : Je commence mon aventure!
